# 🌸 Happy Birthday, Nurse Debalina! 🎂🩺

An interactive, responsive birthday celebration website built in a storybook format honoring **Debalina**—celebrating her special day and praising her dedication, empathy, and heroism as a nurse.

---

## ✨ Features & Story Chapters

1. **Chapter I: The Origin • The Angel in Scrubs**
   - Interactive Cardiac Rhythm ECG Monitor with live pulsing heartbeat line and audible heartbeat audio simulation (`playHeartbeatSound()`).
   - Debalina's 4 Healing Superpowers (The Healing Touch, The Midnight Vigil, Grace Under Pressure, Heart of Pure Gold).
   - Inspiring tribute quotes.

2. **Chapter II: The Healer’s Heart • An Ode to Debalina**
   - Dedicated poetic and heartfelt praise for her as a nurse and real-life superhero.
   - Interactive Stethoscope heart illustration with glowing effects.
   - Interactive "Official Birthday Medical Prescription (`Rx`)" with verifiable stamp effect, prescribing pure relaxation, zero work stress, sweet treats, and infinite hugs!

3. **Chapter III: The Glowing Candle & The Midnight Wish**
   - Realistic SVG/CSS candle with warm glowing halo and flickering flame.
   - Interactive "Make a Wish & Blow the Candle" button (or click candle directly) that plays an audible wind whoosh + chime and releases swirling smoke puffs!
   - Reveals an inspiring golden blessing from the universe.
   - Interactive wish input to send a secret birthday wish to the stars.

4. **Chapter IV: The Grand Cake Cutting Ceremony**
   - 3-tier celebration cake adorned with strawberries, fondant nurse cap/stetho details, and golden lettering.
   - Interactive ceremonial knife with shine effect that animates slicing through the cake.
   - Slicing sound effect (`playCakeSliceSound()`), festive wedge slice extraction, confetti explosions, and floating balloons!
   - Option to virtually "Feed a slice of cake to Debalina" with celebratory counts.

5. **Chapter V: Words from the Heart & The Memory Jar**
   - Vintage wax-sealed personal birthday letter honoring Debalina’s kindness.
   - 3D Interactive Virtual Gift Box that unwraps on click to reveal "The Golden Heart & Angel of Healing Trophy".
   - Interactive Wish Jar where guests can leave messages of love and encouragement.

6. **🎵 Synthesized Music Box & Sound Engine**
   - Zero external audio files required! Synthesizes the Happy Birthday tune, harp arpeggios, heartbeats, candle puff, and celebrations using the browser's native Web Audio API.

---

## 🚀 How to Run the Website

### Option 1: From the root directory (`d:\Birthday`)
```bash
npm run dev
```

### Option 2: From the project directory (`d:\Birthday\Birthday`)
```bash
cd Birthday
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the celebration!
